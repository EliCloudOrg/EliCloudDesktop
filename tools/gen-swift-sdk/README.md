# gen-swift-sdk

`contracts/openapi.yaml` → `sdks/swift/Sources/EliCloudSDK/Generated/`（Swift API）。

契约是唯一协议源（Stage 1）。**手写 DTO 一律不允许**：字段名、可选性、union、
枚举、multipart、二进制响应都由 `apple/swift-openapi-generator` 从契约生成，
生成物入库、可 diff、CI 用 `--check` 防漂移。

## 1. 命令

```bash
# 生成（有 swift 用 native；否则用本机 Docker 里的 swift 镜像）
python tools/gen-swift-sdk/gen_swift_sdk.py

# 只校验：契约改了却没重新生成 → 退出码 1（CI 用）
python tools/gen-swift-sdk/gen_swift_sdk.py --check
```

- `--runner native`：要求 PATH 上有 `swift`（macOS runner 就是这种）。
- `--runner docker`：用 `swift:6.1-jammy`，镜像默认从 `docker.m.daocloud.io` 拉；
  所有缓存（生成器源码、SwiftPM build、`$HOME`）落在 `.local/gen-swift-sdk/`，不入库。
- `--insecure-git`：本机有 TLS 拦截代理时给容器里的 `git clone` 关掉校验（CI 不要用）。
- 需要 `pyyaml`（与 `contracts/` 的 CI 同一个 pin：`pyyaml==6.0.2`）。

## 2. 生成什么

| 文件 | 内容 |
|---|---|
| `Generated/Types.swift` | 契约所有 `components.schemas` 的 Swift 类型（`Sendable` + 显式 `CodingKeys`）；`Operations.*.Input/Output`；`Servers` |
| `Generated/Client.swift` | `Client`（`APIProtocol` 实现）：每个 `operationId` 一个 `async throws` 方法 |

不生成服务端。行为层手写在 `sdks/swift/Sources/EliCloudSDK/`：

- `EliCloudTransport`：URLSession 传输、分类超时（20/8/30/60s）、UA/Bearer 注入、
  `{error,error_description}` + `Retry-After` → `EliCloudError`；
- `SessionStore`（actor）：内存会话；
- `EliCloudClient` / `SsoClient` / `UserInfoClient` / `McClient`：业务接口；
- 图片管线（裁切/缩放/PNG 编码）在客户端 App 侧，不在 SDK。

## 3. 生成器输入 = 契约的「Swift 视图」

`contracts/openapi.yaml` 是唯一协议源，**不改**。生成前脚本会写一份派生输入
`.local/gen-swift-sdk/openapi.swift.yaml`：

- 只做一件事：把 `oneOf/anyOf: [$ref, {type: 'null'}]` 降级成单个 `$ref`；
- 为什么：Swift 官方生成器 1.9.0 把 `.null` 判为不支持的 schema
  （`case .not, .null: return .unsupported`），会把**整个字段静默跳过**
  （`UserProfile.avatar/banner`、`LoginResult.user`、`McHealthStatus.rcon`、
  `McNameListResponse.quota` 都会消失）；
- 为什么安全：这些字段都不在 `required` 里，生成器对可选属性本就产出 `T?`，
  解码显式 `null` 同样得到 `nil`；契约、fixtures 与其它端一个字都不用动；
- 诊断强制可视化：生成器会写 `diagnostics.yaml`，脚本把它打到 CI 日志里——
  以后再有 schema 被跳过，日志里能直接看到，而不是悄悄少字段。

## 4. 版本 pin（三处必须同时改）

| 位置 | 值 |
|---|---|
| `tools/gen-swift-sdk/gen_swift_sdk.py` → `GENERATOR_VERSION` | `1.9.0` |
| `tools/gen-swift-sdk/gen_swift_sdk.py` → `SWIFT_IMAGE` | `swift:6.1-jammy` |
| `sdks/swift/Package.swift` → `swift-openapi-runtime` | `1.9.0`（与生成器同版本线） |

生成器版本变化会改变生成物，必须 **一个 PR 里** 同时更新上面三处并重新生成。

## 5. 生成物规则

- 文件头有 `<auto-generated>`（`tools/audit-official-styles` 据此跳过）；
- 换行统一 LF、结尾补换行 —— Windows 与 macOS 生成结果必须逐字节一致；
- **不要手改 `Generated/`**；契约有问题就改 `contracts/openapi.yaml`，再重新生成。

## 6. CI

`.github/workflows/macos.yml` 的两个步骤：

```yaml
- name: Swift SDK codegen drift check
  run: python tools/gen-swift-sdk/gen_swift_sdk.py --check --runner native
- name: Swift SDK unit + contract tests
  working-directory: sdks/swift
  run: swift test
```

`.github/workflows/swift-sdk-codegen.yml` 是人工触发（也支持 push 触发）的生成作业，
把 `Generated/` 作为 artifact 输出，并打印生成器诊断——没有本机 Swift 时用它重新生成。

`contracts/**`、`tools/gen-swift-sdk/**`、`sdks/swift/**` 任一变更都会触发。
