# Stage 2 共享工具

四端共用的设计令牌、文案、资产、构建配置与审计。所有脚本只依赖标准库（资产导出需要 Pillow），
可在本地和 CI 直接跑。

| 工具 | 命令 | 作用 |
|---|---|---|
| **gen-tokens** | `python tools/gen-tokens/gen_tokens.py [--check]` | `design/tokens.json` → C# / Swift / Kotlin / Python 令牌 + `tokens.official.md` 映射表 + `EXCEPTIONS.md` 令牌登记 + 覆盖率报告 |
| **gen-copy** | `python tools/gen-copy/gen_copy.py [--check]` | `contracts/copy/zh-CN.json` → 主应用 `.resw`（中性+zh-CN）+ `CopyKeys.g.cs`（含 errors.json 映射）、四端资源 + key 映射；缺 key 直接失败 |
| **gen-build-config** | `python tools/gen-build-config/gen_build_config.py --environment local\|prod --platform windows\|macos\|android\|linux\|all [--base-url URL] [--check]` | 构建时注入入口地址 / 版本 / UA；值非法构建失败；生成物不入库 |
| **gen-swift-sdk** | `python tools/gen-swift-sdk/gen_swift_sdk.py [--check] [--runner native\|docker]` | `contracts/openapi.yaml` → `sdks/swift/.../Generated`（官方 swift-openapi-generator，pin 1.9.0）；`--check` 防漂移；同时打印生成器诊断 |
| **audit-official-styles** | `python tools/audit-official-styles/audit.py [--platform all] [--verbose] [--report artifacts/audit.md]` | 扫描裸色值/裸字号/裸圆角/手写控件/假材质；新增违规阻断；例外见 `design/EXCEPTIONS.md` |
| **contract-runner** | `python tools/contract-runner/run.py --list \| --http-smoke \| --target csharp` | 四端 fixtures 回放骨架；HTTP 冒烟不依赖 SDK |
| **export-assets** | `python tools/export-assets.py --check` / `--export artifacts/assets` | 资产清单校验与各端尺寸导出 |
| **screenshots** | `tools/screenshots/README.md` | 截图/无障碍脚本骨架 |
| **ui-windows-smoke** | `tools/ui-windows-smoke.ps1 -Username ... -Password ...` | Windows UIA 冒烟：登录 → 主页/资料/MC/设置，亮/暗截图 + 无障碍树 |

## 1. 生成物规则

- **tokens / copy 是确定性的**：同输入同输出，**入库**；CI 跑 `--check` + `git diff --exit-code` 防漂移。
- **build config 是环境相关的**：生成物**不入库**（prod 地址由 CI secrets 提供），构建前必须先运行生成器。
- 生成文件头都带 `<auto-generated> from ...`；审计工具跳过这些文件。

## 2. 本地从零构建某个端

```powershell
# 1) 公共资产
python tools/gen-tokens/gen_tokens.py
python tools/gen-copy/gen_copy.py

# 2) 该端的构建配置
python tools/gen-build-config/gen_build_config.py --environment local --platform windows

# 3) 该端 hello-world
dotnet build clients/windows/hello/EliCloud.Hello.csproj
dotnet run   --project clients/windows/hello/EliCloud.Hello.csproj
```

## 3. 测试

```powershell
python -m unittest discover -s tools/gen-tokens/tests
python -m unittest discover -s tools/gen-copy/tests
python -m unittest discover -s tools/gen-build-config/tests
python -m unittest discover -s tools/audit-official-styles/tests
```

快照测试在 `tools/*/tests/fixtures/`；失败用例也覆盖（缺 source/ref/reason、缺平台、非法值、重复 key）。

## 4. 官方样式审计

- 规则表见 `audit.py --list-rules`；违规 = 平台代码里出现了官方已有、却手写的值。
- 允许清单：`design/EXCEPTIONS.md` §2 的 JSON（`file` + `line` + `match` + `expiry`）。
- 存量债务：`tools/audit-official-styles/baseline/<platform>.json`，只许减少；
  收紧时运行 `--update-baseline`，并在 PR 里说明减少了多少。
- 失效例外（过期）会让 CI 失败——这是有意的。

## 5. 新增一个令牌 / 一条文案

1. 改 `design/tokens.json`（官方优先；确需自定义要写 `reason/approvedBy/scope`）；
2. 跑 `python tools/gen-tokens/gen_tokens.py`，它会同时更新 `tokens.official.md`、`EXCEPTIONS.md`、覆盖率报告；
3. 四端从生成物引用，不要在页面里写裸值；
4. 文案改 `contracts/copy/zh-CN.json`，再跑 `gen-copy`；不要在某端改完再回写。
