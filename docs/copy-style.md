# 文案风格

界面文案遵循 Microsoft 的 [Writing style for Windows apps](https://learn.microsoft.com/en-us/windows/apps/design/style/writing-style)。
这是一款 **ToC** 产品：用户不关心我们怎么实现，只关心「现在能不能用、我该做什么」。

## 三条基调

| 原则 | 在本工程里的意思 |
|---|---|
| **Be warm and relaxed**（亲切、放松） | 不用术语，不用「错误码」「scope」「RCON」「落库」这类词；出错时是我们来说明情况，不责怪用户 |
| **Be ready to lend a hand**（随时帮忙） | 说清楚「发生了什么」+「接下来怎么办」；能给办法就给办法 |
| **Be crisp and clear**（简洁清楚） | 一句话能说清就不写两句；不解释实现原理 |

## 落地规则

- **对用户说「你」，对自己说「我们」。** 不用「系统」「平台」当主语。
- **主动语态、动作在前。** 按钮写动作（「登录」「添加」「撤回」），不写反应。
- **按钮/标签/复选框不加句号**；完整的说明句才加句号。
- **一句一个信息。** 副标题只写用户能拿来判断的那一条，不堆叠「版本号 + 接口路径 + 参数约束」。
- **不暴露基础设施。** 平台入口地址、主机名、端口、端点路径一律不出现在界面上，
  出错也只说「连不上服务器」。

## 本次改写的对照

| 位置 | 改前 | 改后 |
|---|---|---|
| 登录页标识字段 | 输入用户名或邮箱（但服务端只认用户名，说了做不到） | 标签与占位符都保留 `用户名或邮箱`（服务端已支持邮箱登录）；**注册模式**收窄为 `用户名` + 下方**另画一行**「只能用用户名，不能填邮箱」（`DesignTokens.Hint`，原因见 reactor-feasibility §9.1） |
| 登录页次级按钮 | 注册新账号 / 已有账号，返回登录 | 创建账号 / 返回登录 |
| 登录失败提示 | `EliCloudApiException` 的 `error` + `error_description` | 账号或密码不对，再试一次。 |
| 网络失败提示 | 无法连接 https://146.56.237.33：No such host is known. | 连不上服务器。检查一下网络，然后再试。 |
| 主页加载态 | 正在检测平台服务状态… | 正在查看服务状态… |
| MC 页分组说明 | 来自 /mc/healthz 与 /mc/v1/names 的实时快照 | 现在的运行情况 |
| MC 页分组说明 | 撤回会立刻在 MC 服务端执行 whitelist remove | 撤回后就不能进服务器了 |
| MC 页添加弹窗的备注说明 | 提交是幂等的：重复提交同一个名字只会返回已有条目 | 写清楚为什么需要这个名额，最多 200 字 |
| MC 页卡片 | 服务健康 · status=ok · version=1.0.0 | 服务器 · 运行正常 |
| MC 页卡片 | RCON 通道 · urania-mc:25575 · 延迟 2 ms | 连接速度 · 延迟 2 毫秒 |
| MC 页卡片 | 平台侧白名单人数 · 0 人 | 服务器上的白名单 · 共 0 人 |
| MC 页名额 | 已用 0 / 上限 2，剩余 2 | 还有名额时「还能添加 2 个（上限 2 个）」，用完了说「名额用完了（上限 2 个）」，并在白名单旁提示先撤回一个 |
| MC 页输入说明 | 3–16 位，仅字母/数字/下划线 | 只能用字母、数字和下划线，3 到 16 位 |
| 个人资料页 | 主体标识（sub）/ 授权范围（scope）/ 长期凭据（refresh token） | 昵称、简介、头像、头图 + 用户名、邮箱、登录状态；不展示技术字段 |
| 个人资料页弹窗 | 平台目前没有开放资料修改接口：EliCloud.Sdk 覆盖的是…… | 昵称 1–32 个字符；简介最多 500 个字符；头像/头图支持 PNG、JPEG、WebP |
| 个人资料页昵称 | 昵称为空时点「保存」→「昵称不能为空」 | 新账号昵称默认用户名；不合法时「保存」不可用，不额外提示 |
| 个人资料图片限制 | MAX_AVATAR_BYTES / MAX_BANNER_BYTES | 头像不超过 5 MB，头图不超过 10 MB |
| 个人资料保存失败 | file_service_unavailable / image_too_large | 图片服务暂时不可用，稍后再试 / 图片太大，换一张小一点的 |
| 设置页副标题 | 平台连接与客户端信息 | 账号与应用信息 |
| 设置页外观 | 默认跟随 Windows；也可以固定浅色或深色 | 浅色、深色，或者跟着 Windows 走 |
| 设置页关于 | EliCloud 桌面客户端 v0.1 · 由 WinUI-Reactor 渲染 · 数据来自 EliCloud.Sdk 1.0.0-alpha.2 | EliCloud 桌面版 0.1 |

**保留不动**的是设计稿原文（Hero 的欢迎语、三组分组表头、服务卡片的标题与说明、
Nav 的「主页 / 服务列表 / 设置」、按钮「编辑个人信息」），它们是设计稿的一部分。
